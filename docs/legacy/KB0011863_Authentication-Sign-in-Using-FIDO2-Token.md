## Description

This article provides step-by-step instructions on how to sign into Microsoft services using a security key. A security key is a physical device, such as a USB key or NFC-enabled key, that provides a secure authentication method, reducing reliance on passwords.

## Details

Prerequisites:

Before using a security key to sign in, ensure the following:

  * You have a FIDO2-compliant security key.
  * Your Microsoft account or work/school account allows security key sign-in.
  * You have a supported browser (Microsoft Edge, Google Chrome, or other FIDO2-compatible browsers).
  * Your device has USB or NFC functionality, depending on your security key type.

## Information

Approve a Sign-In request using Security Key

  1. Insert your security key into a USB port on your computer and sign into college application.
  2. Click “Sign-in options”

![](/sys_attachment.do?sys_id=a5338d7c879c6e9033808489cebb354e)

  3. Click “Face, fingerprint, PIN, or security key

![](/sys_attachment.do?sys_id=ad7381fc879c6e9033808489cebb3522)

  4. When prompted to enter a PIN or to use another device.  Click, **Use Another Device**

![A screenshot of a computer](/sys_attachment.do?sys_id=b04b803887186e9033808489cebb354e)

  5. When prompted, select “Security key.”

![A screenshot of a computer screen](/sys_attachment.do?sys_id=494bc4f487186e9033808489cebb35b7)

  6. Enter the pin configured for the device and click OK.

![A screenshot of a computer security](/sys_attachment.do?sys_id=4d4b8c3887186e9033808489cebb35a0)

  7. When prompted to touch your security key, touch the flashing device.

![A screenshot of a security system](/sys_attachment.do?sys_id=c14b0c3887186e9033808489cebb350b)

  8. Once the sign-in request is approved, you will be granted access.
