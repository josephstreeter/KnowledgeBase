## Description

## Information

These are Global settings that are not meant to be edited or changed.
Messaging policies are used to control what chat and channel messaging features are available to users in Teams. You can use the Global (Or-wide default) policy or create one or more custom messaging policies for people in your organization.

## Additional Information and Follow-up

* If you need to create a custom messaging policy, you can do so in the Teams admin center under "Messaging policies."
* For more information on managing messaging policies, refer to the [Microsoft Teams documentation](https://docs.microsoft.com/en-us/microsoftteams/messaging-policies-in-teams).
* If you have any questions or need assistance with messaging policies, please contact the Technology Services Help Desk.
* For any issues related to Teams messaging policies, please escalate to the Teams support team with the following details:
  * Affected user’s UPN (User Principal Name)
  * Date and time of the issue
  * Any error messages or unexpected behavior observed
