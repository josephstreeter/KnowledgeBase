## Description

The default calendar permissions control what level of information can be viewed by all other students, faculty, and staff. The default permissions for new calendars are set to provide only free/busy information.

## Details

Default permissions can be set on your personal calendar, shared mailbox calendar, or resource calendar using the same steps outlined in this document.

Permission levels:

    * **None** : No data is presented. This user will need to contact you to get any information.
    * **Free/Busy time** : View only start/end date/time
    * **Free/Busy time, subject, and location** : View only start/end date/time, subject, and location (except for "private" - which only allows free/busy)
    * **Reviewer** : View full details of all events (except for "private" - which only allows free/busy) - start/end date/time, subject, location, description, attendees, and attachments.

**## Information

**Calendar access control using Outlook (Windows)**

To configure default calendar sharing permissions on your calendar or the calendar of a shared or resource calendar of which you are an owner:

    1. Start Outlook.
    2. Navigate to your calendar by clicking on the **Calendar** tab in the lower left corner (or left side) of your Outlook client.

![](/sys_attachment.do?sys_id=3aaa816087082e1033808489cebb35b7)

    3. At the calendar screen, select the calendar you wish to set default permissions for:

![](/sys_attachment.do?sys_id=7aaa816087082e1033808489cebb35ba)

    4. Right-click on the calendar and then select **"Properties"**. This will open a dialog box that gives you further choices:

![](/sys_attachment.do?sys_id=76aa816087082e1033808489cebb35bc)

    5. Select the **"Permissions"**  tab at the top of the dialog box that opens. The 'Calendar Properties' screen will be displayed:

![](/sys_attachment.do?sys_id=7eaa816087082e1033808489cebb35bf)

The **Default**permissions level will be**"Free/Busy time.** " When set to this value, this setting allows others to view whether you are free or busy but does not allow others to see any detailed information about the event.

    6. Make sure **Default**user is selected and use the options within the 'Read' box to change the desired default permissions for your calendar. To fully restrict others from seeing your calendar, set the**"Read"**permission level to**"None."**This setting will only restrict them from viewing your availability, they will still be able to invite you to a meeting. If you wish others to have greater access to your calendar, set read permissions to**"Full Details"**or**"Free/Busy time, subject, location."**

Please note the **"Permissions"**for the**Anonymous**user.**Anonymous**  users are users who are not part of Madison College. Anonymous calendar sharing has been disabled for Madison College at the recommendation of Microsoft.

    7. When you are done setting your permissions, click on **"Apply"**and then click on**"OK"**  to exit the Calendar Properties dialog box.

### Calendar access control using Outlook Web App

    1. Open **Outlook on the Web**.
    2. Navigate to your **Calendar**
![ootwCalendar1](/sys_attachment.do?sys_id=47aa816087082e1033808489cebb35c3)
    3. At the calendar screen, right-click your default calendar, "**Calendar** ," and select "**Sharing permissions.** "
![ootwCalendar2](/sys_attachment.do?sys_id=4baa816087082e1033808489cebb35c8)
    4. Next to "**My Organization,** " click on the drop-down menu and select the desired permissions level. This will grant that level of permissions to anyone who opens up your calendar. The default permissions level will be "**Can view when I'm busy.** "

The **Default**permissions level will be**"Free/Busy time."**  When set to this value, this setting allows others to view whether you are free or busy but does not allow others to see any detailed information about the event.

* *
* IMPORTANT! If you change the permissions level of "My Organization" to "Can edit," this gives EVERYONE who views your calendar the permission to edit the events on your calendar. This is highly NOT RECOMMENDED.**

![ootwCalendar3](/sys_attachment.do?sys_id=4faa816087082e1033808489cebb35c6)

    5. When you are done settings your permissions, click the "**Done** " button to close the window.
