## Description

Messages that are marked as “junk” are automatically moved to your Junk Email folder. However, spammers and phishing attempts are continually evolving. Junk email received in your inbox can be reported to Microsoft by using the Report Message add-in. Reporting and sending a copy of the message to Microsoft will help them improve their spam filters. Email delivered to your Junk Email folder that is not spam can be marked as a legitimate message using the Report Message add-in as well.

## Details

**What is junk email?**

Junk email messages are typically referred to as spam. These are messages that you don't want to receive that may be advertising products you don't use or find offensive. If you choose the?"Junk"?option, a copy of the message may be?sent to Microsoft to help update their spam filters, and the message will be moved from your Inbox to your Junk Email folder.?

**What is phishing?**

Phishing is the practice of luring you into disclosing personal information, such as bank account numbers and passwords. Often phishing messages look legitimate but have deceptive links that actually open fake websites. If you select?"Phishing," a copy of your message may be sent to Microsoft to help update their filters, and the message will be moved from your Inbox to your Junk Email folder.?

**What is a legitimate email?**

If you know the sender and you're expecting the message, or if you receive a message that's mistakenly marked as junk, you can use the Report Message add-in to mark the message as?"Not Junk." This will move the message from the Junk Email folder back to your Inbox.?

## Information

The following instructions will cover the reporting of suspected phishing emails using the “Report Message Add-In” in the Outlook desktop, web, and mobile clients. This will allow you to report the message as “Junk” or “Phishing” and send a copy of the email to Microsoft.

### Outlook Desktop (Windows or Mac)

The Report Message button add-in will appear at the top of your Outlook client.

To report an email as a phishing email:

1. Open the message and click the Report Message button

    ![Screenshot showing the Report Message button in the Outlook client](/sys_attachment.do?sys_id=7de3c2591bb35a10417dcaa1604bcb03)

2. The Report Message Add-in will present you with several different options:

    * Junk - Report the message as Spam
    * Phishing - Report the message as a Phish
    * Not Junk - Report an email incorrectly reported as Junk as a legitimate message
    * Options - See options for the Report Message Add-in
    * Help - Display Help

    ![Screenshot showing the options for the Report Message Add-in](/sys_attachment.do?sys_id=31e382591bb35a10417dcaa1604bcbab)

    Choosing Options from the Report Message button allows you to choose whether messages are automatically sent to Microsoft when they're reported as junk or phishing attempts.

Change your Report Message options:

1. Choose Options from the Report Message button on the Ribbon

    ![Screenshot showing options for messages reported as junk or phishing attempts](/sys_attachment.do?sys_id=42e3c2591bb35a10417dcaa1604bcb10)

2. Select one of the following options:

    * Always send a copy of the message to Microsoft
    * Never send a copy of the message to Microsoft
    * Ask before sending a copy of the message to Microsoft

3. Once you've made your selection, choose Save. You'll see the following message in the InfoBar in the message header confirming your changes were saved successfully.

    ![Text of message that says your changes were saved.](/sys_attachment.do?sys_id=79e3c2591bb35a10417dcaa1604bcb05)

### Outlook Web (aka OWA)

In the web client, there is not a Report Message button like there is in the Desktop client

To report an email as a phishing email:

1. Click the message and click the Junk button.

    ![Screenshot showing the Junk button in the Outlook Web client](/sys_attachment.do?sys_id=75e3c2591bb35a10417dcaa1604bcb0e)

2. Select either Junk or Phishing from the drop-down menu

  a. If you click Junk you will receive the following dialog box.

  ![Screenshot showing the dialog box for reporting junk email](/sys_attachment.do?sys_id=79e3c2591bb35a10417dcaa1604bcb0c)

  b. Click Report (Optionally you can check the box to automatically report)

  c. If you click Junk you will receive the following dialog box. Click Report:

  ![Screenshot showing the dialog box for reporting junk email](/sys_attachment.do?sys_id=f1e382591bb35a10417dcaa1604bcba9)
