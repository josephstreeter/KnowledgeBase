## Description

The following instructions outline the steps required to set an Automatic Reply on a Shared Mailbox.

## Details

In order to perform these steps you must have been delegated access to the Shared Mailbox. This activity can also be performed in the Outlook  Desktop Client.

## Information

    1. Log in to the Outlook Web App (<<https://outlook.com/madisoncollege.edu>>)

    2. Click on your profile picture in the upper-right corner of the window

![](/sys_attachment.do?sys_id=1a99aafe1b17d2909446975b234bcbd1)

    3. Select ‘Open another mailbox’ in the menu

![](/sys_attachment.do?sys_id=5699aafe1b17d2909446975b234bcb7f)

    4. Type in the name of the shared mailbox and select ‘Open’

![](/sys_attachment.do?sys_id=1699aafe1b17d2909446975b234bcb81)

    5. Once you are logged into the shared mailbox, click on settings icon to access the shared mailbox settings

![](/sys_attachment.do?sys_id=1699aafe1b17d2909446975b234bcbd5)

    6. In the search box, begin to type ‘automatic replies’ and select the option when it appears

![](/sys_attachment.do?sys_id=9699aafe1b17d2909446975b234bcbd3)

    7. Configure your automatic reply

![](/sys_attachment.do?sys_id=1299aafe1b17d2909446975b234bcb85)

    7.        1. Set “Automatic replies on”
       2. (Optional) Check the box for “Send replies only during a time period” and enter a start and end date and time.
       3. Enter the message to be sent both to people inside and outside of your organization
    8. Click ‘Save’

![](/sys_attachment.do?sys_id=9299aafe1b17d2909446975b234bcb83)
