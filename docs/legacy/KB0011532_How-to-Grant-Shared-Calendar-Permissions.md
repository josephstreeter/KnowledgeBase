## Description

Grant a user(s) permissions to a shared mailbox calendar.

## Details

    * Users who have full access permissions to shared mailboxes have the ability to grant permissions to other users who do not have access to the shared mailbox without submitting a ServiceNow ticket.
    * Full Access and Calendar permissions are two separate permissions.

      * Full Access Permissions: This permission provides a user(s) full access to everything about the mailbox. Granting this permission will require submitting a ticket to the Help Desk.
      * Calendar Permissions: This permission only provides a user(s) permission to the calendar which does not require submitting a ticket to the Help Desk.
    * These instructions ONLY provides a user(s) certain permissions to the calendar. This does not provide any other permissions like viewing the inbox or sending emails from the shared mailbox.
    * A user(s) needing permissions to a calendar does not necessarily need full access permissions to the shared mailbox.

## Information

1. From your Outlook client, click on the Calendar icon. This should be located at the bottom left of your Outlook client.

    ![](/sys_attachment.do?sys_id=0f6c2af21b57d2909446975b234bcbff)

2. Locate the shared mailbox, right-click and select **Properties**.

3. Click the **Permissions** tab.

4. Add/remove users and provide their permissions. 

    Please note: Do not remove or modify the entries **Default** _and Anonymous**_!**

5. Click **OK**.

After granting permissions to a calendar for a specific user, the calendar does not show up in their Outlook client automatically and will need to be added manually. Here are the steps to add the calendar manually:

1. From your calendars in Outlook, right-click on **Shared Calendars** and select **Add Calendar**.

    ![](/sys_attachment.do?sys_id=036caef21b57d2909446975b234bcbef)

2. Click **Open Shared Calendar...**.

3. Click **Name...**.

4. From the **Address Book** dropdown list, select **Global Address List**.

    ![](/sys_attachment.do?sys_id=cf6c2af21b57d2909446975b234bcbfa)

5. Search for the name of the shared calendar. If you see it on the list, highlight the name and click **OK**.

    ![](/sys_attachment.do?sys_id=8f6c2af21b57d2909446975b234bcbfd)

6. Click **OK**.
