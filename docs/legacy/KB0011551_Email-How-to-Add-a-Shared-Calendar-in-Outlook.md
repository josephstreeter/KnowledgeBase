## Description

How to add a shared calendar in Outlook.

## Details

Shared calendars do not automatically show up in users calendars when granting them permissions. You will need to add the shared calendar manually.

## Information

1. In Outlook, go to your calendars.

2. Right-click on **Shared Calendars**, highlight **Add Calendar** and select **Open Shared Calendar**.

3. In the **Name** textbox, enter the alias name of the shared mailbox.

It is important you do not include the **@madisoncollege.edu**.
For example, if the shared mailbox's email address is [MyTeamCalendar@madisoncollege.edu,](mailto:MyTeamCalendar@madisoncollege.edu,) specify **MyTeamCalendar** in the textbox depicted in the screenshot below.

    ![](/sys_attachment.do?sys_id=4b04c2591bb35a10417dcaa1604bcb86)

6. Click **OK**.
