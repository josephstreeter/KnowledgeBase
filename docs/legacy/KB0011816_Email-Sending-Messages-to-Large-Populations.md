## Description

There are message-sending limits in Microsoft Exchange that have been configured to reduce the impact of phishing emails sent from employee and student accounts which have been compromised. Attackers like to use compromised accounts to send phishing emails because the message appears to be more legitimate as it is coming from someone inside the organization.

## Details

Types of groups that can be used to distribute messages:

    * **Exchange Distributions Groups** – Sometimes called Distribution Lists, these groups  can be used to distribute messages. Distribution Groups are published in the Global Address List.

These groups can be created by request. Distribution Groups may have owners assigned to manage the members or they may be dynamic, meaning the members are populated based on data (e.g., employee type, cost center, location, etc.). For more information, see the [article](https://madisoncollege.service-now.com/kb_view.do?sysparm_article=KB0011818) on requesting a new Distribution Group.

    * **Exchange Mail-Enabled Security Groups** – Groups that can be used to grant access permissions to resources and are configured to distribute messages. Mail-Enabled Security Groups are created and maintained by Technology Services and are not commonly used.

    * **Microsoft 365 Groups** – Groups that are used to allow people to collaborate and work together on files, chat, calls, and online meetings.

These groups provide a SharePoint Teams site, a shared calendar, and can function as a Distribution Group or similar to a Shared Mailbox. Microsoft 365 Groups are an underlying component of Microsoft Teams and Microsoft Planner.

Microsoft 365 Groups can be created and managed by navigating to the “My Groups” portal ([https://mygroups.microsoft.com](https://mygroups.microsoft.com)). From the “My Groups” portal group owners can add and remove both owners and members.

**Outlook Contact Groups** – Contact Groups are groups that are created in the Outlook client. These groups function similar to Distribution Groups except that they are only accessible to the user who created them within the Outlook client.
