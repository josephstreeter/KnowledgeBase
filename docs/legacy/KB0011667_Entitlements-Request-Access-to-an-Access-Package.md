## Description

Entitlement Management is a feature that allows for the lifecycle management of entitlements. Entitlement Management provides assignment, review, and expiration of access requests to resources using automated workflows. These workflows and resources are grouped into Access Packages. The resources in these cases are groups or Teams, applications, and SharePoint sites.

## Details

Requesting of entitlements is performed in the My Access portal. The requestor signs into the [https://myaccess.microsoft.com](https://myaccess.microsoft.com) portal, finds the Access Package they want and requests access to it.

Alternately, an email is sent to a user by someone wishing to grant access to the recipient. This email will include a direct link to the Access Package in question (e.g. [https://myaccess.microsoft.com/@<directory_hint>#/access-packages/<access_package_id](https://myaccess.microsoft.com/@%3cdirectory_hint%3e#/access-packages/<access_package_id)>) The process is largely the same except the requestor does not have to search for the Access Package.

Some Access Packages are “Admin Assigned.” This means that access for a user can be granted or removed by the manager of an Access Package manually. Therefore, Admin Assigned Access Packages are not displayed in the My Access portal.

## Information

**User Request:**

The following instructions are for an end user looking to request access to a resource

1. Navigate to the “My Access Portal” ([https://myaccess.microsoft.com/](https://myaccess.microsoft.com/)) to see what Access Packages are available

    ![](/sys_attachment.do?sys_id=ac8b66b21b57d2909446975b234bcb88)

2. The requestor will click “Request” to the right of the Access Package that is being requested
3. The requestor will enter the reason for making the request in the “Business justification” box, if required, and click “Submit”

**View Active Entitlements:**

1. Click “Active” on the “My Access” portal page

    ![](/sys_attachment.do?sys_id=ec8b66b21b57d2909446975b234bcb85)

2. The “Active” page shows
    1. Access Package name
    2. Access Package description
    3. Resources assigned by the Access Package (i.e. groups, SharePoint sites, applications)
    4. Start Date – when the Access Package was assignment delivered
    5. End Date – When the Access Package assignment will expire, if an expiration is configured
3. By clicking the ellipsis under “Actions” you can:

    ![](/sys_attachment.do?sys_id=2c8b66b21b57d2909446975b234bcb8a)

    1. Click “Remove” to remove your assignment to the Access Package
    2. Create a link to share the Access Package with others

**Review Request History:**

  1. Click “Request history” of the left pane of the “My Access” portal
  2. Review the list of Access Package requests
  3. Click “View” to the right of the request to review the request details
  4. Requests that are still pending may be canceled by selecting the radio button to the left of the request and clicking “Cancel request” near the top of the screen
