## Description

How to Add/Remove a Shared Mailbox in Outlook.

## Details

When users submit a request for TS to grant users Full Access permissions to a shared mailbox. The user has the ability to view the shared mailbox using OWA which is the preferred method. However, these instructions provides the user an option to add shared mailboxes to Outlook.

Please note:** Be aware if you have more than 2 shared mailboxes in Outlook may slow down performance of your client especially if the shared mailbox is highly used. If you are receiving slow performances in Outlook, it is recommended removing the shared mailboxes from Outlook and view them via OWA. Second, you may run into issues where the mailbox from the Outlook client may not reflect the same emails in OWA. This perhaps may be an issue with your Outlook Profile not syncing the mailbox properly from the cloud. A couple potential fixes that can be done._

* Rebuild the users Outlook profile
* Reapply users Full Access permissions to the mailbox having issues
* View the mailbox using OWA (recommended)

## Information

1. From Outlook, click File > Account Settings > Account Settings.

2. Click the **Data Files** tab.

3. Click **Settings** icon.

4. Click the **Advanced** tab.

### How to Add a Shared Mailbox

1. Click **Add**.

2. In the **Add mailbox:** textbox, type the shared mailbox alias.

3. Click **OK**.

4. Click **OK**. Your Outlook client will freeze momentarily for this to take effect.

5. Click **Close**.

6. You should see the mailbox on the left side of your Outlook client. This may take some time to sync depending on the size of the mailbox. If you click on the mailbox, you'll notice at the bottom right of Outlook there is a message indicating the the contents of this mailbox is updating. Once complete, the message will indicated that the mailbox is "Up to date".

### How to Remove a Shared Mailbox

1. Highlight the shared mailbox.
2. Click **Remove**.
3. Click **OK**.
4. Click **Close**.
