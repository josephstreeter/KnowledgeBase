## Description

Instructions for approving sign-ins using push notifications in the Microsoft Authenticator App.

## Details

To approve sign-ins using Microsoft Authenticator push notifications:

1. When prompted during sign-in, a notification will appear on your mobile device.
2. Open the Microsoft Authenticator App.
3. Tap "Approve" to confirm the sign-in.
4. If you did not initiate the sign-in, tap "Deny".

**Tips:**

- Enable notifications for the app on your device.
- Always deny requests you did not initiate.

**Issue Resolution:**

- If notifications are not received, check device notification settings and internet connectivity.
- If unable to approve, restart the app and device, and ensure the app is updated.
- For persistent issues, sign in using an alternate method and contact IT support.

## Additional Information and Follow-up

Contact IT support if you do not receive notifications or have trouble approving sign-ins.
