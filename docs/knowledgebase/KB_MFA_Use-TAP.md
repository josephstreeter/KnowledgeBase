## Description

Instructions for requesting and using a Temporary Access Pass for authentication.

## Details

To request and use a Temporary Access Pass (TAP):

1. Contact your IT administrator to request a TAP.
2. Receive the TAP code securely.
3. Go to the sign-in page for Microsoft 365 or Entra ID.
4. Enter your username and select "Sign in with Temporary Access Pass".
5. Enter the TAP code.
6. Register new authentication methods if prompted.
7. Complete sign-in and setup.

**Tips:**

- TAP is time-limited; use it before it expires.
- Register backup methods during TAP sign-in.

**Issue Resolution:**

- If TAP does not work, check for typos and ensure it has not expired.
- If unable to register new methods, try a different browser or device.
- If you do not receive a TAP, contact IT and confirm your identity.

**References:**

- [Temporary Access Pass](https://learn.microsoft.com/en-us/azure/active-directory/authentication/temporary-access-pass-overview)

## Additional Information and Follow-up

Contact IT support if you need a TAP or have trouble signing in.
