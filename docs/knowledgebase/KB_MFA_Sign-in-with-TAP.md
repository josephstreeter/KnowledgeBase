## Description

Steps to sign in using TAP for first-time setup or lost device scenarios.

## Details

To sign in using Temporary Access Pass (TAP):

1. Obtain a TAP from your IT administrator.
2. Go to the sign-in page for Microsoft 365 or Entra ID.
3. Enter your username and select "Sign in with Temporary Access Pass".
4. Enter the TAP code provided.
5. Register new authentication methods if prompted.
6. Complete sign-in and setup.

**Tips:**

- TAP is time-limited; use it before it expires.
- Register backup methods during TAP sign-in.

**Issue Resolution:**

- If TAP does not work, check for typos and ensure it has not expired.
- If unable to register new methods, try a different browser or device.
- If you do not receive a TAP, contact IT and confirm your identity.

**References:**

- [Sign in with TAP](https://learn.microsoft.com/en-us/azure/active-directory/authentication/temporary-access-pass-overview)

## Additional Information and Follow-up

Contact IT support if you need a TAP or have trouble signing in.
