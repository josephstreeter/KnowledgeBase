## Description

Steps to use a FIDO2 security key to sign in to Microsoft 365 services.

## Details

To use a FIDO2 security key to sign in:

1. Go to the sign-in page for Microsoft 365 or Entra ID.
2. Enter your username and select "Sign in with security key".
3. Insert or tap your FIDO2 key when prompted.
4. Enter your key PIN if required.
5. Complete sign-in.

**Tips:**

- Use a supported browser and device.
- Register backup keys for redundancy.

**Issue Resolution:**

- If key is not recognized, try a different USB port or NFC reader and check for firmware updates.
- If PIN is not accepted, reset your key or contact IT.
- If unable to sign in, use an alternate method and contact IT for troubleshooting.

**References:**

- [Use FIDO2 key to sign in](https://learn.microsoft.com/en-us/azure/active-directory/authentication/howto-authentication-passwordless-security-key)

## Additional Information and Follow-up

Contact IT support if you have trouble using your FIDO2 key.
