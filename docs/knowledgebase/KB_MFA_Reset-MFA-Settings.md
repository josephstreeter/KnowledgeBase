## Description

Instructions for resetting your multi-factor authentication settings.

## Details

To reset your multi-factor authentication (MFA) settings:

1. Go to [My Sign-Ins Security Info](https://mysignins.microsoft.com/security-info).
2. Sign in and locate your registered authentication methods.
3. Remove outdated or unused methods.
4. Add new methods as needed (Authenticator App, FIDO2 key, phone).
5. Save changes and test sign-in.

**Tips:**

- Register multiple methods for backup.
- Contact IT support if you cannot access your account.

**Issue Resolution:**

- If unable to remove or add methods, clear browser cache and cookies, then retry.
- If changes do not save, try a different browser or device.
- For persistent issues, contact IT support for manual reset.

**References:**

- [Reset MFA settings](https://learn.microsoft.com/en-us/azure/active-directory/user-help/user-help-security-info-reset)

## Additional Information and Follow-up

Contact IT support for help resetting your MFA settings.
