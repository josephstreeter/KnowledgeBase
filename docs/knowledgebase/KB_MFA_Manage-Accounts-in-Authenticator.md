## Description

Instructions for adding or removing accounts in the Microsoft Authenticator App.

## Details

To add or remove accounts in the Microsoft Authenticator App:

**Add an Account:**

1. Open the Microsoft Authenticator App on your mobile device.
2. Tap the "+" icon to add a new account.
3. Choose the account type (Work, School, Personal).
4. Scan the QR code or enter the setup code provided by your organization.
5. Follow prompts to complete setup.

**Remove an Account:**

1. Open the Authenticator App.
2. Tap the account you want to remove.
3. Tap the three dots (menu) and select "Remove account".
4. Confirm removal.

**Tips:**

- Always keep backup methods registered.
- Remove old accounts you no longer use.

**Issue Resolution:**

- If unable to add an account, check for app updates and ensure you are scanning the correct QR code.
- If removal fails, restart the app and try again. If the issue persists, reinstall the app.
- For work/school accounts, ensure your device is compliant with company policies.
