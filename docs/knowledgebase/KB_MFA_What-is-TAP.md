## Description

Overview of Temporary Access Pass (TAP) and its use cases for authentication.

## Details

Temporary Access Pass (TAP) is a time-limited, single-use pass issued by IT for onboarding, recovery, or lost device scenarios.

**Use Cases:**

- First-time setup of passwordless authentication.
- Recovery when all other authentication methods are unavailable.
- Device replacement or migration.

**How TAP Works:**

- TAP is generated by an administrator and sent securely to the user.
- User enters TAP during sign-in to register new authentication methods.
- TAP expires after a set period or after use.

**Issue Resolution:**

- If you do not receive a TAP, contact IT and confirm your identity.
- If TAP does not work, check for typos and ensure it has not expired.
- If unable to register new methods, try a different browser or device.

**References:**

- [Temporary Access Pass overview](https://learn.microsoft.com/en-us/azure/active-directory/authentication/temporary-access-pass-overview)

## Additional Information and Follow-up

Contact your IT support to request a TAP if needed.
