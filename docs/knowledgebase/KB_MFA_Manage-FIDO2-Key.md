## Description

Instructions for removing or replacing a FIDO2 security key.

## Details

To remove or replace a FIDO2 security key (including YubiKey):

**Remove a Key:**

1. Go to [My Sign-Ins Security Info](https://mysignins.microsoft.com/security-info).
2. Sign in and locate your registered FIDO2 keys (YubiKey or other brands) under "Security keys".
3. Click "Remove" next to the key you want to delete.

**Add a New Key:**

1. Select "Add method" > "Security key".
2. Choose "USB device" or "NFC device" depending on your key model (YubiKey or other).
3. Insert or tap your key when prompted.
4. Set a PIN for your key if required.
5. Complete registration and test sign-in.

**Tips:**

- Remove lost or unused keys promptly.
- Register more than one key (YubiKey or other) for backup and redundancy.
- Store backup keys securely.
- Use the official [YubiKey Manager](https://www.yubico.com/products/services-software/download/yubikey-manager/) for advanced YubiKey features.

**Issue Resolution:**

- If unable to remove a key, refresh the page and try again. If the issue persists, clear browser cache or use a different browser.
- If new key registration fails, check for firmware updates and use a supported browser.
- For YubiKey-specific issues, consult Yubico support or use YubiKey Manager for troubleshooting.
