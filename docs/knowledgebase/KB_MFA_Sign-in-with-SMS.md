## Description

Steps to sign in using SMS codes for MFA.

## Details

To sign in using SMS codes for MFA:

1. Go to the sign-in page for Microsoft 365 or Entra ID.
2. Enter your username and password.
3. When prompted, select "Text me a code".
4. Enter the code received via SMS.
5. Complete sign-in.

**Tips:**

- Ensure your mobile number is registered and up to date.
- If you do not receive a code, check your phone signal or contact IT.

**Issue Resolution:**

- If SMS code is not received, verify your number and check for carrier issues.
- If code is delayed or expired, request a new code and restart your device.
- For persistent issues, contact IT support for manual verification.

**References:**

- [Sign in with SMS](https://learn.microsoft.com/en-us/azure/active-directory/user-help/user-help-security-info-sign-in)

## Additional Information and Follow-up

Contact IT support if you have trouble receiving or entering SMS codes.
