## Description

Common issues and solutions for SMS code delivery problems.

## Details

Common issues and solutions for SMS code delivery problems:

**Issue:** Not receiving SMS codes

- Check your phone signal and carrier.
- Ensure your mobile number is registered and up to date.
- Restart your device.
- Contact IT support for manual verification if the issue persists.

**Issue:** SMS code delayed or expired

- Wait a few minutes and request a new code.
- Restart your device and check for carrier issues.
- Contact IT if delays persist.

**Issue:** Unable to register phone number

- Clear browser cache and cookies, then retry.
- Try a different browser or device.
- Contact IT support for manual registration.
