## Description

Instructions for registering a FIDO2 security key for passwordless authentication.

## Details

To register a FIDO2 security key for passwordless sign-in:

1. Go to [My Sign-Ins Security Info](https://mysignins.microsoft.com/security-info).
2. Sign in and select "Add method" > "Security key".
3. Choose USB or NFC key type and follow prompts.
4. Insert or tap your FIDO2 key when prompted.
5. Set a PIN for your key if required.
6. Complete registration and test sign-in.

**Tips:**

- Use a supported FIDO2 key (see Microsoft documentation).
- Register more than one key for backup.

**Issue Resolution:**

- If your key is not recognized, try a different USB port or NFC reader and check for firmware updates.
- If PIN is not accepted, reset your key or contact IT.
- If unable to register, use a supported browser and check for OS/browser updates.

**References:**

- [Register a FIDO2 security key](https://learn.microsoft.com/en-us/azure/active-directory/authentication/howto-authentication-passwordless-security-key)

## Additional Information and Follow-up

Contact IT support if you encounter issues registering your key.
