## Description

Instructions for registering your mobile number for SMS-based multi-factor authentication.

## Details

To register your mobile number for SMS-based MFA:

1. Go to [My Sign-Ins Security Info](https://mysignins.microsoft.com/security-info).
2. Sign in and select "Add method" > "Phone".
3. Enter your mobile number and select "Text me a code".
4. Enter the code received via SMS to verify your number.
5. Your phone will be registered for SMS MFA.

**Tips:**

- Use a mobile number you always have access to.
- Update your number if it changes.

**Issue Resolution:**

- If you do not receive the SMS code, check your phone signal and verify your number is correct.
- If code is delayed or expired, request a new code and restart your device.
- If unable to register, contact IT for assistance.

**References:**

- [Register phone for MFA](https://learn.microsoft.com/en-us/azure/active-directory/user-help/user-help-security-info-add-phone-number)

## Additional Information and Follow-up

Contact IT support if you have trouble registering your number.
