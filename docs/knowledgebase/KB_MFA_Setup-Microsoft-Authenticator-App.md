## Description

Step-by-step instructions for setting up the Microsoft Authenticator App for multi-factor authentication (MFA).

## Details

To set up the Microsoft Authenticator App for MFA:

1. Download and install the Microsoft Authenticator App from the App Store or Google Play.
2. Open the app and tap "+" to add an account.
3. On your computer, go to [My Sign-Ins Security Info](https://mysignins.microsoft.com/security-info).
4. Sign in and select "Add method" > "Authenticator App".
5. Scan the QR code displayed on your computer with the app.
6. Approve the test notification to complete setup.

**Tips:**

- Enable app lock for added security.
- Register backup authentication methods.

**Issue Resolution:**

- If you do not receive notifications, check device notification settings and internet connectivity.
- If unable to scan QR code, ensure your camera is working and the code is not expired.
- If setup fails, update the app and try again or restart your device.
